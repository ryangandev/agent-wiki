# Agent Wiki

Shared root: `__WIKI_ROOT__`.

Choose the relevant mode inside that directory:

- Capture: `_system/ingest.md`, after a confirmed decision, corrected lasting requirement or verified reusable lesson.
  Assess current conversation before completing substantive work; capture qualifying evidence without waiting for the whole session to end or a separate "remember this" request, within authorized scope.
- Recall: `_system/recall.md`, only when historical context is needed and missing.
- Maintenance: `_system/maintain.md`, for an authorized maintenance run including configured incremental session review.

The capture checkpoint uses current context, not a preload of the wiki.
Skip routine progress, duplicate conclusions and facts already adequately documented in the repository.
Search the compact index only when a candidate merits capture or recall; read relevant sections, not Home, every summary or source archives.
No qualifying knowledge means no capture or status report.
Consult `_system/GUIDE.md` only for policy questions.
