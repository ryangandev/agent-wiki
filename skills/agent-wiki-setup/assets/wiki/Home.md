# Agent Wiki

This is a private knowledge base shared by the agents you connect.
It starts empty; absence of knowledge is a valid state.

- `wiki/projects/`: project intent and links to relevant decisions.
- `wiki/decisions/`: choices, reasons, scope and changes over time.
- `wiki/topics/`: research findings, evidence and open questions.
- `wiki/methods/`: verified reusable lessons.
- `sources/`: minimal supporting evidence, read only for tracing a claim.
- `_system/`: operating instructions, generated index and processing state.

Agents start from a targeted index search, not this page or the entire vault.
See [[__WIKI_LINK_PREFIX___system/GUIDE|the operating policy]] when needed.
